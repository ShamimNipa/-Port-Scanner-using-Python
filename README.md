# Port-Scanner-using-Python
A Python-based TCP port scanner that identifies open ports on a target IP address or hostname using socket programming and multithreading.

## Features
- Scan a single or multiple targets
- Specify a custom port range
- Detect open TCP ports
- Attempt basic banner detection
- Concurrent scanning using a thread pool

## Technologies
- Python
- Socket Programming
- Multithreading

## Usage

Run the script:

```bash
python index.py
```

Enter the target IP address or hostname and the desired port range when prompted.

## Disclaimer

Use this tool only on systems you own or have explicit permission to scan.
